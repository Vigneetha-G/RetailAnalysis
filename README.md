# RetailAnalysis
Retail Data Analysis | Python & SQL
A project analyzing over 1 million global retail transactions to uncover sales trends, top products, and customer patterns. Built a robust data pipeline: loaded CSV data into MySQL with SQLAlchemy, then cleaned and analyzed the data using Pandas.

Explored sales by product, country, and seasonality
Performed customer segmentation and retention analysis
Delivered actionable business insights with visualizations
**Key skills:** Python, Pandas, MySQL, SQLAlchemy, data cleaning, analytics
